# Презентация для ресторатора

Одностраничная презентация «RestAI за столом» — как работают приложения гостя,
официанта и кухни. Сделана для показа ресторатору: вечер за одним столом, девять
шагов, на каждом рядом экран гостя и экран официанта.

```
presentation/
  index.html    вся страница: вёрстка, стили и скрипт в одном файле
```

Ничего собирать не нужно — это обычный статический файл. Единственная внешняя
зависимость: шрифты Google Fonts (Unbounded, Golos Text, IBM Plex Mono). Без
интернета страница откроется системными шрифтами, вёрстка не поедет.

## Где смотреть

После публикации на GitHub Pages (тот же механизм, что у `card/`):

**https://wadim1970.github.io/RestAI/presentation/**

Локально — просто открыть `presentation/index.html` в браузере, сервер не нужен.

## Что внутри

| Раздел | О чём |
|---|---|
| Четыре части, одна база | Приложения гостя, официанта, терминал кухни, кабинет ресторана |
| Это не QR-меню с картинками | Сравнение с обычным QR-меню по шести пунктам |
| Девять шагов от посадки до отзыва | Основная часть: экран гостя и экран официанта в один и тот же момент |
| Правила продаж задаёте вы | Коммерческая политика ресторана как экран настроек |
| Заготовки: от наклейки до подсказки | Кухонный контур: терминал → печать наклейки → сканер → ИИ |
| Видно, кто действительно продаёт | Контроль работы официантов |
| Официанты приходят к вам сами | Биржа смен |
| Что настраиваете вы | Кабинет ресторана |
| Где здесь деньги | Экономика для ресторатора |
| Что где живёт | Схема архитектуры |

Переключатель в начале таймлайна показывает только экраны гостя, только экраны
официанта или оба сразу — удобно, когда показываешь с телефона.

## Правки

Весь текст лежит прямо в `index.html` рядом с разметкой — можно править руками,
пересобирать ничего не нужно. Тёмная и светлая темы переключаются сами по
настройке системы у того, кто открыл страницу.

Таблица в разделе «Видно, кто действительно продаёт» заполнена демонстрационными
цифрами — это отмечено подписью под ней. Перед показом конкретному ресторану их
имеет смысл заменить на реальные.
