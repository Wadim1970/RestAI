# Визитка-PWA

> В репозитории две визитки: `card/` — Вадим Фоменко, `card-zuev/` — Алексей
> Зуев. Папки самостоятельные и одинаковые по устройству, отличаются только
> объектом `CARD`, именем в манифесте и именем кэша в `sw.js`. Эта инструкция
> описывает обе; чтобы сделать третью, скопируйте любую папку и смотрите
> раздел «Ещё одна визитка» в конце.

Статическая страница-визитка, которую можно поставить на домашний экран телефона:
человек сканирует QR → открывается карточка → «добавить на экран» → появляется
иконка с логотипом компании, по нажатию открывается карточка без адресной строки
браузера и работает даже без интернета.

Ничего собирать не нужно: это обычные файлы, которые кладутся на любой статический
хостинг. Обязательное условие — **HTTPS** (без него браузер не разрешит установку).

```
card/
  index.html              вся карточка: вёрстка, данные, логика
  manifest.webmanifest    имя, иконки, цвет — то, что делает страницу «приложением»
  sw.js                   service worker: офлайн + без него Android не предложит установку
  icons/                  иконки для домашнего экрана (сгенерированы из логотипа)
  img/photo.jpg           фотография
  img/logo.png            логотип в шапке
  img/qr.png              QR-код (генерируется, см. ниже)
  tools/make-qr.py        генератор QR-кода
```

## 1. Свои данные

Всё содержимое — в одном объекте `CARD` в начале `<script>` в `index.html`.
Строки помечены комментарием `// ЗАМЕНИТЬ`:

```js
const CARD = {
  firstName: 'Имя',
  lastName:  'Фамилия',
  role:      'Основатель',
  phone:     '+79991234567',
  telegram:  'username',        // без @
  ...
}
```

Пустое поле `''` — соответствующая кнопка просто не отрисуется.

### Фотография

Фотография лежит в `img/foto.jpg`. Логотип компании — `img/Blackxxxx.png`;
из него собраны `img/logo.png` для шапки и весь набор `icons/` для домашнего
экрана (скрипт перегенерации — в истории коммитов, повторяется при замене
логотипа).

Файл кладётся как есть, обрезать не нужно — один и тот же снимок работает и в
кружке, и в полном размере. Кадр в кружке задают две строки в `CARD`:

```js
photo:      'img/foto.jpg',
photoZoom:  150,          // насколько приблизить: 100 — снимок целиком, больше — крупнее
photoFocus: '56% 22%',    // какая точка снимка окажется в кружке
```

Без приближения в кружок попадёт весь кадр вместе с фоном, поэтому `photoZoom`
подтягивает лицо, а `photoFocus` двигает окно кадрирования: меньше первое число —
окно левее, меньше второе — выше. Подбирается на глаз за пару правок; после
замены фотографии числа обычно приходится подкрутить.

По клику на аватарку снимок открывается целиком — без обрезки, во весь экран.
Размер файла роли не играет: маленький снимок увеличится, большой ужмётся.
Чем крупнее исходник, тем чётче он будет в развёрнутом виде, но специально
искать снимок побольше не нужно — обычного портрета с телефона хватает.

### Реквизиты

По кнопке «Реквизиты» карточка переворачивается обратной стороной. Содержимое —
список в `CARD.details`:

```js
details: [
  { label: 'ИНН', value: '7701234567' },
  { label: 'БИК', value: '044525003' },
]
```

Порядок строк здесь = порядок на экране, лишние можно удалить, свои — дописать.
Незаполненные значения не показываются, а **пока не заполнено ни одной строки,
кнопка «Реквизиты» вообще не появляется** — пустая обратная сторона хуже, чем
её отсутствие.

На обратной стороне есть кнопка «Скопировать реквизиты»: отдаёт всё одним
текстом, чтобы собеседник вставил в бухгалтерию, не перенабирая вручную.

## 2. Публикация

Раздаётся через GitHub Pages по адресу
**https://wadim1970.github.io/RestAI/card/**

Включается один раз: Settings → Pages → Source: «Deploy from a branch», ветка с
папкой `card/`, folder `/ (root)` → Save. Первая сборка занимает пару минут.

Адрес не зависит от того, с какой ветки идёт раздача, — при переезде на `main`
он останется прежним и перегенерировать QR не придётся.

В корне репозитория лежит пустой `.nojekyll`: без него Pages прогоняет файлы
через Jekyll, который молча пропускает всё, что начинается с подчёркивания.

Все пути внутри карточки относительные, так что папку `card/` можно перенести
куда угодно — хоть в корень отдельного домена. Тогда адрес меняется, и QR
нужно перегенерировать.

## 3. QR-код

Генерируется **после** того, как известен итоговый адрес:

```bash
pip install segno pillow
python3 card/tools/make-qr.py https://вашадрес/card/
```

Появятся `img/qr.png` (для кнопки «QR-код» внутри карточки), `img/qr-print.png`
(крупный, с логотипом в центре) и `img/qr-print.svg` (вектор для печати).
Пока `img/qr.png` нет — кнопка «QR-код» на карточке не показывается.

Проверьте готовый код камерой до того, как печатать его на бейдже или стенде.

## Как это выглядит у гостя

* **Android / Chrome** — внизу появляется свой баннер «Установить», одно нажатие.
* **iPhone / Safari** — системного окна установки в iOS нет вообще: карточка
  показывает подсказку «Поделиться → На экран «Домой»». Важно: именно Safari,
  из Chrome на iOS добавить на экран нельзя.
* Кнопка **«Сохранить контакт»** отдаёт `.vcf` — контакт с фото, должностью и
  ссылками уезжает прямо в телефонную книгу.

## Правки в дальнейшем

После изменения `index.html` или иконок поднимите версию кэша в `sw.js`
(`const CACHE = 'card-v1'` → `'card-v2'`), иначе у тех, кто уже установил
карточку, какое-то время будет открываться старая копия.

## Ещё одна визитка

Скопируйте готовую папку целиком и поменяйте в копии пять мест:

1. `index.html` → объект `CARD`: имя, должность, контакты, `photoZoom`
   и `photoFocus` под новый снимок;
2. `index.html` → `<title>`, `og:title` и `apple-mobile-web-app-title`
   (подпись под иконкой на iOS);
3. `manifest.webmanifest` → `name` и `short_name` (подпись под иконкой
   на Android);
4. `sw.js` → `const CACHE`. **Обязательно своё имя**: кэш общий на весь
   домен, и одинаковые имена означают, что визитки затирают кэш друг другу;
5. `index.html` → ключ `card:install-hidden:<кто>`. Тоже общий на домен:
   с одинаковым ключом отказ от подсказки на одной визитке погасил бы её
   и на второй.

Потом положите фотографию в `img/foto.jpg` и сгенерируйте QR под новый
адрес: `python3 <папка>/tools/make-qr.py https://.../<папка>/`.
