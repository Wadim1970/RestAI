# site/ — сайт restai.pro

Здесь лежит всё, что относится к сайту restai.pro. Сейчас это заглушка главной
страницы по макету из Figma; дальше сюда же добавляются остальные страницы,
стили и ассеты.

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | Главная страница (заглушка) |
| `styles.css` | Все стили страницы |
| `images/` | Фото, логотипы, иконки |

Сборки нет — это статика. Открывается двойным кликом по `index.html`
или любым статическим сервером:

```bash
python3 -m http.server 8080 --directory site
# http://localhost:8080/
```

## images/

| Файл | Размер | Что это |
|---|---|---|
| `chef.webp` / `chef.png` | 730×878 | Шеф-повар, главное изображение. WebP — 49 КБ, PNG — 500 КБ (фолбэк) |
| `logo.webp` / `logo.png` | 256×256 | Логотип. Взят из `card/img/logo.png` — в макете он был 48×48, для ретины этого мало |
| `favicon-32.png` | 32×32 | Фавиконка |
| `apple-touch-icon.png` | 180×180 | Иконка для iOS |
| `icon-192.png`, `icon-512.png` | — | Иконки про запас (PWA-манифест, шеринг) |

Изображения подключены через `<picture>`: браузер берёт WebP, старые —
PNG. У `<img>` проставлены `width`/`height`, чтобы вёрстка не прыгала при
загрузке.

## Адаптив

Макет был только под десктоп (1923×1051), мобильная версия сделана с нуля.

* **≥ 1200px** — как в макете: две колонки, текст слева, шеф справа,
  водяной знак `DIGITAL` у правого края, жёлтая наклейка поверх плашки
  и кнопки ДЕМО.
* **900–1199px** — те же две колонки, шеф и типографика уменьшаются
  пропорционально.
* **≤ 900px** — одна колонка: меню сворачивается в бургер, дальше текст,
  плашка интеграций, кнопка ДЕМО, наклейка (поворот ослаблен до −3°,
  чтобы не ломать сетку), шеф в самом низу. Водяной знак скрыт.
* **≤ 480px** — ещё компактнее: меньше логотип, наклейка −2°.

Размеры шрифтов на `clamp()`, высота экрана на `dvh` (корректно на iOS),
учтены вырезы через `env(safe-area-inset-*)`, у страницы `overflow: clip` —
повёрнутая наклейка не может вызвать горизонтальную прокрутку.
Проверено на 1920, 1440, 1280, 1100, 820, 430 и 360 px — горизонтальной
прокрутки нет нигде.

Доступность: бургер с `aria-expanded`, закрывается по Esc и по клику
снаружи, видимая обводка фокуса, ссылка «к основному содержанию»,
`prefers-reduced-motion`.

## Решения, которые я принял сам

1. **Пункты меню и ВХОД не кликабельны.** Разделов сайта пока нет, вести
   они никуда не могут, а битые ссылки на заглушке выглядят хуже, чем их
   отсутствие. Визуально они на месте, как в макете. Кликабельны только
   «Контакты», кнопка **ДЕМО** и адрес на наклейке — все три ведут на
   `mailto:ceo@restai.pro`. Когда появятся реальные страницы, достаточно
   поменять `<span class="nav__item">` на `<a href="…">`.
2. **Шрифты.** Gabarito, Manrope и Agbalumo из макета есть в Google Fonts и
   подключены как есть. Двух других там нет:
   * `Century Gothic` → `Jost` (та же геометрическая антиква, есть 400/700).
     У кого установлен Office, подхватится оригинальный Century Gothic —
     он стоит первым в стеке.
   * `Cygre Book` (вес 350, пункты меню) → `Manrope`.

   Если нужны именно оригиналы — пришлите файлы шрифтов, положим их в
   `site/fonts/` и подключим через `@font-face`.
3. **Наклейка перекрывает кнопку ДЕМО** — так в макете, и это осмысленно:
   сайта ещё нет, кнопка не должна выглядеть рабочей. Прозрачность 63%
   оставлена, кнопка просвечивает. Клик по кнопке при этом работает:
   у наклейки `pointer-events: none`, кликабелен только адрес почты.
4. **Тире в лиде.** В макете «RestAI - умная экосистема», поставил длинное
   тире «—»: по-русски это типографически верно.

## Публикация на restai.pro

GitHub Pages умеет отдавать только корень репозитория или `/docs`, папку
`site/` напрямую он не увидит. Поэтому публиковать нужно через GitHub
Actions — тогда папка может называться как угодно.

1. Settings → Pages → Source: **GitHub Actions**.
2. Добавить `.github/workflows/pages.yml`:

```yaml
name: Deploy site
on:
  push:
    branches: [main]
    paths: ['site/**', '.github/workflows/pages.yml']
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: pages
  cancel-in-progress: true

jobs:
  deploy:
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - uses: actions/checkout@v4
      - uses: actions/configure-pages@v5
      - uses: actions/upload-pages-artifact@v3
        with:
          path: site
      - id: deployment
        uses: actions/deploy-pages@v4
```

3. Settings → Pages → Custom domain: `restai.pro`, затем включить
   **Enforce HTTPS** (кнопка появится после проверки домена).
4. DNS у регистратора домена:

   | Тип | Имя | Значение |
   |---|---|---|
   | A | `@` | `185.199.108.153` |
   | A | `@` | `185.199.109.153` |
   | A | `@` | `185.199.110.153` |
   | A | `@` | `185.199.111.153` |
   | AAAA | `@` | `2606:50c0:8000::153` |
   | AAAA | `@` | `2606:50c0:8001::153` |
   | AAAA | `@` | `2606:50c0:8002::153` |
   | AAAA | `@` | `2606:50c0:8003::153` |
   | CNAME | `www` | `wadim1970.github.io` |

Workflow намеренно не добавлен в репозиторий: сейчас Pages собирается с
другой ветки и отдаёт презентацию, его включение это переключит. Добавим,
когда решите публиковать.
